# BMI Classification Machine Learning Project

## 📝 Problem Statement
The goal of this project is to predict the **BMI Index** based on Gender, Height, and Weight. This classification helps in understanding and monitoring health categories effectively.

## 📊 Dataset
- **Features:** Gender, Height, Weight.
- **Target:** BMI Index (Categories).

## 🛠️ Workflow & Methodology

### 1. Data Cleaning
- Handled missing values.
- Removed duplicate entries to ensure data integrity.
- Encoded categorical data (Gender) into numerical format.

### 2. Exploratory Data Analysis (EDA)
- Visualized data patterns using **Histograms**, **Scatter Plots**, and **Count Plots**.
- Analyzed the correlation between height/weight and the BMI category.

### 3. Machine Learning Models
We implemented and compared three different algorithms:
1. **Logistic Regression**
2. **Support Vector Machine (SVM)**
3. **Random Forest**

## 🏆 Results
After comparing the models based on **Accuracy Score**, the results showed that:
- **Random Forest** achieved the highest accuracy and performed best in predicting health categories.

## 📌 Conclusion
The Random Forest model can effectively predict the BMI Index, providing a reliable tool for health classification based on simple physical attributes.

## 💻 Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn, Seaborn, Matplotlib
